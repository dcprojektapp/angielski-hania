# 🌟 Uczymy się Angielskiego! - English Class 4

Interaktywna aplikacja edukacyjna do nauki języka angielskiego dla ucznia klasy 4 szkoły podstawowej, oparta na materiale z podręcznika *English Class 4*.

## ✨ Funkcje
- **Dwa moduły ćwiczeń:**
  - 📝 **Tłumaczenia zdań** (z języka polskiego na angielski)
  - 🧩 **Zadania z luką** (uzupełnianie zdań po angielsku)
- **Wybór materiału:**
  - Czasownik *to be* (am / is / are)
  - Czasownik *have got* (have / has got)
  - Czasownik *can* (can / cannot)
  - *Super Mix* (wszystko na raz)
- **Podsumowanie wyników:**
  - Licznik poprawnych i błędnych odpowiedzi (dobrze / źle)
  - Wynik procentowy i zapamiętywanie najlepszego wyniku (gwiazdki)
  - Przyjazny, kolorowy interfejs dopasowany dla dzieci
